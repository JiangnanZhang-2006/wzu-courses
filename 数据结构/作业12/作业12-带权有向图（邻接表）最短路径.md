## 4134-创建图

## 问题描述

本题要求你实现**带权有向图（邻接表）的初始化操作**。

本题使用**带权邻接表**表示有向图。每个顶点维护一条出边链表，链表中每个节点存储一个邻居顶点编号及对应的边权重。与无向图不同，有向图的邻接表**只存储出边**，不存储入边。

---

## 数据结构定义

```c
typedef enum { OK = 1, ERROR = 0 } Status;

typedef struct WDAdjNode {
    int               vertex;
    int               weight;
    struct WDAdjNode* next;
} WDAdjNode;

typedef struct {
    WDAdjNode** heads;   /* 出边邻接表头指针数组 */
    int         size;
    int         edgeCount;
} WDALGraph;
```

---

## 函数说明

```c
WDALGraph* CreateGraph(int size);
```

**返回值：** 成功返回图指针；`size <= 0` 或分配失败返回 `NULL`

**初始状态：** `size` 和 `edgeCount` 初始化，`heads` 数组全为 `NULL`
