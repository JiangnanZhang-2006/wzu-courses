## 3956-创建节点

### 问题描述

本题要求你实现**二叉搜索树的节点创建操作**。

二叉搜索树（BST）是一种有序二叉树：每个节点的值严格大于其左子树中所有节点的值，严格小于其右子树中所有节点的值。本实验版本不允许重复值，每个值在树中至多存在一个节点。每个节点额外维护 `parent` 指针，指向其父节点，根节点的 `parent` 为 `NULL`。

---

## 数据结构定义

```c
typedef enum { OK = 1, ERROR = 0 } Status;

typedef struct BSTNode {
    int data;
    struct BSTNode* left;
    struct BSTNode* right;
    struct BSTNode* parent; /* 父节点指针，根节点为 NULL */
} BSTNode;
```

---

## 函数说明

```c
BSTNode* CreateNode(int val);
```

**参数：**
- `val`：节点存储的整数值

**返回值：**
- 成功：返回新创建的节点指针
- 失败（内存分配失败）：返回 `NULL`

**初始状态要求：**
- `data` 初始化为 `val`
- `left`、`right`、`parent` 均初始化为 `NULL`

## 3957-插入元素

### 问题描述

本题要求你实现**二叉搜索树的插入操作**。

BST 的插入须维护有序性：待插入值小于当前节点则向左子树递归，大于则向右子树递归，等于则插入失败（不允许重复值）。插入成功时须正确设置新节点的 `parent` 指针。

---

## 数据结构定义

```c
typedef enum { OK = 1, ERROR = 0 } Status;

typedef struct BSTNode {
    int data;
    struct BSTNode* left;
    struct BSTNode* right;
    struct BSTNode* parent;
} BSTNode;
```

---

## 函数说明

```c
Status Insert(BSTNode** root, int val);
```

**参数：**
- `root`：根节点指针的指针
- `val`：待插入的整数值

**返回值：**
- `OK`：成功新建节点（`val` 不存在于树中）
- `ERROR`：`val` 已存在于树中，或 `root == NULL`

**特殊情况处理：**
- `root == NULL` 时返回 `ERROR`
- `val` 已存在时树结构不变，返回 `ERROR`

**parent 指针维护要求：**
- 新建节点的 `parent` 须指向其在树中的父节点
- 根节点（树为空时插入）的 `parent` 为 `NULL`

**依赖接口（由系统提供，无需实现）：**
- `BSTNode* CreateNode(int val)` — 创建并返回一个新节点，`data=val`，`left=right=parent=NULL`

## 3963-中序前驱

### 问题描述

本题要求你实现**二叉搜索树的中序前驱查询**。

节点 `node` 的中序前驱是中序遍历序列中紧排在 `node` 之前的节点，即 BST 中值严格小于 `node->data` 的最大节点。`parent` 指针的存在使得在没有左子树时可以沿父链向上查找前驱，无需从根重新遍历。

---

## 数据结构定义

```c
typedef enum { OK = 1, ERROR = 0 } Status;

typedef struct BSTNode {
    int data;
    struct BSTNode* left;
    struct BSTNode* right;
    struct BSTNode* parent;
} BSTNode;
```

---

## 函数说明

```c
BSTNode* Predecessor(BSTNode* node);
```

**参数：**
- `node`：待查询前驱的节点指针

**返回值：**
- 存在前驱：返回前驱节点指针
- 不存在前驱（`node` 为中序最小节点）或 `node == NULL`：返回 `NULL`

**语义规则：**
- 若 `node` 有左子树，则前驱为左子树中值最大的节点
- 若 `node` 无左子树，则沿 `parent` 链向上，找到第一个使当前节点是其父节点右子的祖先节点，该祖先即为前驱；若不存在这样的祖先，则无前驱

**依赖接口（由系统提供，无需实现）：**
- `BSTNode* GetMax(BSTNode* root)` — 返回以 `root` 为根的子树中值最大的节点；`root == NULL` 时返回 `NULL`
