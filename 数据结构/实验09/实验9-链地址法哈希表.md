## 3997-创建节点

### 问题描述

本题要求你实现**哈希表的节点创建操作**。

本实验使用**链地址法**处理哈希冲突。哈希表由若干"桶"组成，每个桶是一条链表，链表中的每个节点存储一个键值对（key-value）。`CreateNode` 负责创建一个新的链表节点。

---

## 数据结构定义

```c
typedef enum { OK = 1, ERROR = 0 } Status;

typedef struct HashNode {
    int key;
    int value;
    struct HashNode* next;
} HashNode;

typedef struct {
    HashNode** buckets;
    int size;   /* 桶数量 */
    int count;  /* 已存储键值对数量 */
} HashTable;
```

---

## 函数说明

```c
HashNode* CreateNode(int key, int value);
```

**参数：**
- `key`：节点存储的键
- `value`：节点存储的值

**返回值：**
- 成功：返回新创建的节点指针
- 失败（内存分配失败）：返回 `NULL`

**初始状态要求：**
- `key` 初始化为 `key`
- `value` 初始化为 `value`
- `next` 初始化为 `NULL`

### 输入

本题的输入数据由测试代码自动完成，你无需编写输入处理。

### 输出

本题的输出数据由测试代码自动完成，你无需编写输出处理。

## 数据范围

- `key`：整数，满足 |key| ≤ 10^8
- `value`：整数，满足 |value| ≤ 10^8

---

## 提交说明

**参数：**
