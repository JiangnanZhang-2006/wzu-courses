## 3979-创建节点

### 问题描述

本题要求你实现**带计数二叉搜索树的节点创建操作**。

带计数二叉搜索树（Count-aware BST）在普通 BST 的基础上，为每个节点增加了 `count` 字段，记录该值在逻辑上出现的次数；同时增加 `parent` 字段，指向父节点，根节点的 `parent` 为 `NULL`。插入重复值时不新建节点，而是将对应节点的 `count` 加一；删除时先将 `count` 减一，只有 `count` 归零时才真正删除节点。

---

## 数据结构定义

```c
typedef enum { OK = 1, ERROR = 0 } Status;

typedef struct BSTNode {
    int data;
    int count;              /* 该值的出现次数，初始为 1 */
    struct BSTNode* left;
    struct BSTNode* right;
    struct BSTNode* parent; /* 父节点指针，根节点为 NULL */
} BSTNode;
```

---

## 函数说明

```c
BSTNode* CreateNode(int val);
```

**参数：**
- `val`：节点存储的整数值

**返回值：**
- 成功：返回新创建的节点指针
- 失败（内存分配失败）：返回 `NULL`

**初始状态要求：**
- `data` 初始化为 `val`
- `count` 初始化为 `1`
- `left`、`right`、`parent` 均初始化为 `NULL`

## 3980-插入元素

### 问题描述

本题要求你实现**带计数 BST 的插入操作**。

与普通 BST 的关键区别在于：当插入的值已存在于树中时，**不新建节点**，而是将该节点的 `count` 加一并返回 `ERROR`；插入新值时，除维护 BST 的左右子结构外，还须正确设置新节点的 `parent` 指针。

---

## 数据结构定义

```c
typedef enum { OK = 1, ERROR = 0 } Status;

typedef struct BSTNode {
    int data;
    int count;
    struct BSTNode* left;
    struct BSTNode* right;
    struct BSTNode* parent;
} BSTNode;
```

---

## 函数说明

```c
Status Insert(BSTNode** root, int val);
```

**参数：**
- `root`：根节点指针的指针
- `val`：待插入的整数值

**返回值：**
- `OK`：成功新建节点（`val` 不存在于树中）
- `ERROR`：`val` 已存在，执行 `count++` 后返回

**特殊情况处理：**
- `root == NULL` 时返回 `ERROR`

**parent 指针维护要求：**
- 新建节点的 `parent` 须指向其在树中的父节点
- 根节点（树为空时插入）的 `parent` 为 `NULL`

## 3983-中序遍历

### 问题描述

本题要求你实现**带计数 BST 的中序遍历**。

与普通 BST 中序遍历的关键区别：每个节点的值需要输出 **`count` 次**，而非仅输出一次。因此遍历结果为含重复值的非递减序列，总元素个数等于所有节点 `count` 之和。

---

## 数据结构定义

```c
typedef enum { OK = 1, ERROR = 0 } Status;

typedef struct BSTNode {
    int data;
    int count;
    struct BSTNode* left;
    struct BSTNode* right;
    struct BSTNode* parent;
} BSTNode;
```

---

## 函数说明

```c
void InOrder(BSTNode* root, int* result, int* cnt);
```

**参数：**
- `root`：根节点指针
- `result`：输出数组，长度不小于所有节点 `count` 之和
- `cnt`：计数器指针，**调用前须由调用方初始化为 0**

**功能：**
按左-根-右顺序遍历，对每个节点将 `data` 写入 `result` 共 `count` 次。

**结果特性：**
输出为含重复值的**非递减序列**（允许相邻元素相等）。

**特殊情况：**
- `root == NULL` 时直接返回

## 3987-中序前驱

### 问题描述

本题要求你实现**带计数 BST 的中序前驱查询**。

节点 `node` 的中序前驱是中序遍历序列中紧排在 `node` 之前的节点，即 BST 中值严格小于 `node->data` 的最大节点。`parent` 指针的存在使得在没有左子树时可以沿父链向上查找前驱，无需从根重新遍历。

---

```c

    int data;
    int count;
    struct BSTNode* left;

    struct BSTNode* parent;
```
