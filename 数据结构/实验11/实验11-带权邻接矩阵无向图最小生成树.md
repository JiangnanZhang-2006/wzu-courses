## 4068-创建图

### 问题描述

本题要求你实现**带权邻接矩阵无向图的初始化操作**。

本题使用**带权邻接矩阵**表示无向图。`matrix[i][j]` 存储顶点 `i` 与顶点 `j` 之间边的权重，值为 `0` 表示无边，正整数表示边的权重。矩阵需动态分配。

`CreateGraph` 负责分配并初始化一张空图：动态分配行指针数组和每一行，将矩阵所有元素置为 `0`，初始化顶点数和边数。

---

## 数据结构定义

```c
typedef enum { OK = 1, ERROR = 0 } Status;

typedef struct {
    int** matrix;    /* matrix[i][j] = 权重，0 表示无边 */
    int   size;      /* 顶点数量 */
    int   edgeCount; /* 边数 */
} WGraph;
```

---

## 函数说明

```c
WGraph* CreateGraph(int size);
```

**参数：**
- `size`：顶点数量

**返回值：**
- 成功：返回新创建的图指针
- 失败（`size <= 0` 或内存分配失败）：返回 `NULL`

**初始状态要求：**
- `size` 初始化为 `size`
- `edgeCount` 初始化为 `0`
- `matrix` 为 `size × size` 的二维数组，所有元素初始化为 `0`
