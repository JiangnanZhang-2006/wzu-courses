## 4033-创建图

### 问题描述

本题要求你实现**邻接矩阵无向图的初始化操作**。

## 数据结构定义

本题使用**邻接矩阵**表示无向图。`matrix[i][j] = 1` 表示顶点 `i` 与顶点 `j` 之间有边，`0` 表示无边；顶点编号从 `0` 开始，矩阵需动态分配。

```c
typedef enum { OK = 1, ERROR = 0 } Status;

typedef struct {
    int** matrix;    /* 邻接矩阵，matrix[i][j]=1 表示 i-j 有边 */
    int   size;      /* 顶点数量 */
    int   edgeCount; /* 边数 */
} MGraph;
```

## 函数说明

```c
MGraph* CreateGraph(int size);
```

**参数：**
- `size`：顶点数量

**返回值：**
- 成功：返回新创建的图指针；`size` 初始化为 `size`，`edgeCount` 初始化为 `0`，`matrix` 为 `size × size` 的二维数组，所有元素初始化为 `0`
- 失败（`size <= 0` 或内存分配失败）：返回 `NULL`
