## 3860-判断两棵树结构相同

### 问题描述

本题要求你实现 **判断两棵二叉树结构是否相同的操作**。

两棵二叉树结构相同是指：

* 两棵树的形状完全一致
* 每个对应位置的节点都具有相同的子树结构
* 不考虑节点的数据值是否相同

例如，以下两棵树结构相同：

```
树1:          树2:
    A             X
   / \           / \
  B   C         Y   Z
```

以下两棵树结构不同：

```
树1:          树2:
    A             X
   /               \
  B                 Y
```

该操作常用于：

* 树的形状比较
* 模式匹配
* 结构验证
