## 4111-创建图

### 问题描述

本题要求你实现**带权有向图的初始化操作**。

本题使用**带权邻接矩阵**表示有向图。`matrix[i][j]` 存储从顶点 `i` 到顶点 `j` 的有向边权重，值为 `0` 表示无边。与无向图不同，有向图的邻接矩阵**不一定对称**：`matrix[i][j]` 非零不代表 `matrix[j][i]` 也非零。

---

## 数据结构定义

```c
typedef enum { OK = 1, ERROR = 0 } Status;

typedef struct {
    int** matrix;   /* matrix[i][j] = 权重，0 表示无边 */
    int   size;     /* 顶点数量 */
    int   edgeCount;/* 有向边总数 */
} WDGraph;
```

---

## 函数说明

```c
WDGraph* CreateGraph(int size);
```

**参数：** `size`：顶点数量

**返回值：**
- 成功：返回新创建的图指针
- 失败（`size <= 0` 或内存分配失败）：返回 `NULL`

**初始状态要求：**
- `size` 初始化为 `size`，`edgeCount` 初始化为 `0`
- `matrix` 为 `size × size` 的二维数组，所有元素初始化为 `0`

## 4123-Dijkstra 算法

## 问题描述

本题要求你实现**Dijkstra 单源最短路径算法**。

从源点 `src` 出发，贪心地选取当前距离最小的未访问顶点，依次松弛其出边，直到所有可达顶点的最短距离确定。

**适用条件**：所有边权重必须为正数。负权边会导致结果不正确。

**Tie-breaking 规则**：距离相同时，优先选择编号较小的顶点。

---

## 数据结构定义

```c
typedef enum { OK = 1, ERROR = 0 } Status;

typedef struct {
    int** matrix;
    int   size;
    int   edgeCount;
} WDGraph;
```

---

## 函数说明

```c
Status Dijkstra(WDGraph* g, int src, int* dist, int* prev);
```

**参数：**
- `dist`：输出数组，`dist[i]` 为 src 到 i 的最短距离；不可达时为 `INT_MAX`
- `prev`：输出数组，`prev[i]` 为最短路径中 i 的前驱顶点编号；无前驱时为 `-1`

**返回值：** `OK`；参数非法或 `g == NULL` 时返回 `ERROR`

**依赖接口（由系统提供）：**
- 无，可直接操作 `g->matrix`
