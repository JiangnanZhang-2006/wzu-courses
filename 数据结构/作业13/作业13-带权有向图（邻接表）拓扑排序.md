## 4171-创建图

## 问题描述

本题要求你实现**带权有向图（邻接表）的初始化操作**。

## 数据结构定义

本题使用**带权邻接表**表示有向图。每个顶点维护一条出边链表，链表中每个节点存储出边目标顶点编号及边权重；顶点编号从 `0` 开始。

```c
typedef enum { OK = 1, ERROR = 0 } Status;

typedef struct WDAdjNode {
    int               vertex; /* 出边目标顶点编号 */
    int               weight; /* 边的权重 */
    struct WDAdjNode* next;   /* 下一个邻接节点 */
} WDAdjNode;

typedef struct {
    WDAdjNode** heads;   /* 出边邻接表头指针数组，长度为 size */
    int         size;    /* 顶点数量 */
    int         edgeCount; /* 有向边总数 */
} WDALGraph;
```

## 函数说明

```c
WDALGraph* CreateGraph(int size);
```

**参数：**
- `size`：顶点数量

**返回值：**
- 成功：返回新创建的图指针；`size` 初始化为 `size`，`edgeCount` 初始化为 `0`，`heads` 数组长度为 `size`，每个元素初始化为 `NULL`
- 失败（`size <= 0` 或内存分配失败）：返回 `NULL`
