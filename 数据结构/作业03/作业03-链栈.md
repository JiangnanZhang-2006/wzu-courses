## 3784-创建与初始化

### 问题描述

本题要求你实现**链栈**的创建与初始化操作。

链栈是栈的链式存储实现，具有以下特点：

* 使用链表存储栈中元素，每个节点动态分配
* 栈顶指针 `top` 指向链表的首节点（栈顶元素）
* 使用 `size` 字段记录栈中元素个数
* 遵循 **LIFO（后进先出）** 原则
* **无容量限制**（理论上只受系统内存限制）

---

```c
    ElementType data;
    struct StackNode* next;
} StackNode;

    StackNode* top;  // 栈顶指针(指向栈顶节点)
    int size;        // 栈中元素个数
} LinkStack;

typedef enum { OK = 1, ERROR = 0 } Status;
```
