## 3839-广义表构建二叉树

### 问题描述

本题要求你实现 **二叉树的广义表构建操作**。

二叉树是一种重要的非线性数据结构，具有以下特点：

* 每个结点最多有两个子结点（左子树和右子树）
* 具有递归定义特性
* 结构层次分明
* 是树结构中最基础、最常见的一种形式

在实际应用中，二叉树常常以字符串形式进行表示，其中一种常见方式就是 **广义表表示法**。

广义表是一种使用括号和逗号描述父子关系的表示方式：

* 结点字符表示当前结点
* 圆括号 `()` 表示该结点有子树
* 逗号 `,` 用于分隔左子树与右子树

例如：

```
A(B(D,E),C(F,G))
```

表示的二叉树结构为：

```
      A
     / \
    B   C
   / \ / \
  D  E F  G
```

其中：

* `A` 为根结点
* `B(D,E)` 表示 B 的左子树为 D，右子树为 E
* `C(F,G)` 表示 C 的左子树为 F，右子树为 G

## 广义表语法规则

构建时必须遵循以下语法规则：

1. **叶子结点**


2. **带子树结点**

   ```
   A(左子树,右子树)
   ```

3. **只有左子树**

   ```
   A(B)
   A(B,)
   ```

4. **只有右子树**

   ```
   A(,C)
   ```

5. **左右子树均存在**

   ```
   A(B,C)
   ```

6. 每个左括号 `(` 必须有对应的右括号 `)`。

7. 逗号 `,` 用于分隔左右子树。

8. 字符串中的空格字符应被忽略。

1. 访问根结点
2. 先序遍历左子树

* 表达式树的前缀表达式输出
