## 3766-创建与初始化

### 问题描述

本题要求你实现**顺序栈**的创建与初始化操作。

顺序栈是栈的顺序存储实现，具有以下特点：

* 使用连续的存储空间（数组）存储栈中元素
* 用 `top` 指针指示栈顶位置（-1 表示空栈）
* 遵循 **LIFO（后进先出）** 原则
* 有固定的最大容量限制

## 3770-入栈

### 问题描述

本题要求你实现**顺序栈**的入栈操作。

入栈操作是栈的核心操作之一，将新元素添加到栈顶。栈遵循 **LIFO（后进先出）** 原则，最后入栈的元素将最先出栈。

入栈操作需要注意：

* 检查栈是否已满
* 更新栈顶指针
* 存储新元素

你需要实现以下 **1 个函数**：

### 入栈操作 

```c
Status Push(SeqStack* S, ElementType x);
```

**功能要求**：

* 将元素 `x` 入栈（添加到栈顶）
* 成功返回 `OK`（值为 1），失败返回 `ERROR`（值为 0）
* 参数为指向栈结构的指针和待入栈元素

**操作步骤**：

1. 检查 `S` 是否为 `NULL`
2. 检查栈是否已满（调用 `IsFull(S)` 或直接判断 `S->top >= MAXSIZE - 1`）
3. 若已满，返回 `ERROR`
4. 若未满，先将 `top` 加 1，再将 `x` 存入 `data[top]`
5. 返回 `OK`

**特殊情况处理**：

* 若 `S == NULL`，返回 `ERROR`

### 6）IsValidPopSeq - 判断出栈序列是否有效

```c
Status IsValidPopSeq(const int* push, const int* pop, int n);
```

**功能要求：**

- 判断给定入栈序列 `push[]` 和出栈序列 `pop[]` 是否匹配
- `push[]` 是按顺序入栈的元素序列（`push[0]` 先入栈，`push[n-1]` 后入栈）
- `pop[]` 是期望的出栈序列（`pop[0]` 先出栈，`pop[n-1]` 后出栈）
- 有效返回 `OK`（1），无效返回 `ERROR`（0）

**匹配规则：**

- 模拟栈的入栈和出栈过程
- 按照 `push[]` 的顺序依次入栈
- 每次入栈后，检查栈顶是否等于当前期望出栈的元素（`pop[]` 中的当前元素）
- 如果相等，则出栈并移动出栈序列指针
- 继续入栈下一个元素，重复上述过程
- 所有元素入栈完毕后，如果栈中还有元素，继续出栈直到栈空
- 如果最终能按 `pop[]` 顺序完全出栈，则序列有效

**失败条件：**

- `push == NULL` 或 `pop == NULL`：返回 `ERROR`
- `n <= 0`：返回 `ERROR`
- 模拟过程中无法按 `pop[]` 顺序出栈：返回 `ERROR`

**算法提示：**

1. 创建一个辅助栈 `S`
2. 使用两个指针：`pushIdx` 指向 `push[]`，`popIdx` 指向 `pop[]`
3. 遍历 `push[]`，依次将元素入栈
4. 每次入栈后，检查栈顶是否等于 `pop[popIdx]`
5. 如果相等，出栈并 `popIdx++`，重复检查（可能连续出栈多个）
6. 所有元素入栈后，检查 `popIdx` 是否等于 `n`
7. 如果 `popIdx == n`，说明所有元素都按预期出栈，返回 `OK`
8. 否则返回 `ERROR`
