## 4018-创建哈希表

### 问题描述

本题要求你实现**开放寻址哈希表的初始化操作**。

本作业使用**开放寻址法**处理哈希冲突，探测策略为**二次探测**。开放寻址法将所有键值对直接存储在槽数组中，每个槽有三种状态：`EMPTY`（从未使用）、`OCCUPIED`（存有数据）、`DELETED`（已删除，保留标记供探测使用）。

为保证二次探测能覆盖所有槽，**表大小应为质数**，且负载因子（已存储数量 / 表大小）应保持在 0.5 以下。

---

## 数据结构定义

```c
typedef enum { OK = 1, ERROR = 0 } Status;
typedef enum { EMPTY = 0, OCCUPIED = 1, DELETED = 2 } SlotState;

typedef struct {
    int       key;
    int       value;
    SlotState state;
} Slot;

typedef struct {
    Slot* slots;
    int   size;     /* 槽总数 */
    int   count;    /* OCCUPIED 槽数量 */
    int   deleted;  /* DELETED 槽数量 */
} OAHashTable;
```

---

## 函数说明

```c
OAHashTable* CreateTable(int size);
```

**参数：**
- `size`：槽的数量（应为质数）

**返回值：**
- 成功：返回新创建的哈希表指针
- 失败（`size <= 0` 或内存分配失败）：返回 `NULL`

**初始状态要求：**
- `size` 初始化为 `size`
- `count` 和 `deleted` 初始化为 `0`
- `slots` 数组长度为 `size`，每个槽的 `state` 初始化为 `EMPTY`

### 输出

## 数据范围

- `size`：正整数，题目保证为质数

## 4021-插入键值对

## 问题描述

本题要求你实现**开放寻址哈希表的插入操作**。

使用二次探测寻找插入位置。探测过程中需处理以下情况：遇到 `OCCUPIED` 且 key 相同时更新 value；遇到 `DELETED` 槽时记录位置但继续探测（因为同 key 可能在更后面）；遇到 `EMPTY` 时在此插入（或复用之前记录的 `DELETED` 槽）。

---

## 数据结构定义

```c
typedef enum { OK = 1, ERROR = 0 } Status;
typedef enum { EMPTY = 0, OCCUPIED = 1, DELETED = 2 } SlotState;

typedef struct {
    int       key;
    int       value;
    SlotState state;
} Slot;

typedef struct {
    Slot* slots;
    int   size;
    int   count;
    int   deleted;
} OAHashTable;
```

---

## 函数说明

```c
Status Insert(OAHashTable* ht, int key, int value);
```

**参数：**
- `ht`：哈希表指针
- `key`：待插入的键
- `value`：待插入的值

**返回值：**
- `OK`：key 不存在，成功新建（`count++`）
- `ERROR`：key 已存在（已更新 value，count 不变）或 `ht == NULL` 或表满

**插入规则：**
- 沿探测序列找到第一个可用位置插入
- 若探测中遇到 `DELETED` 槽，记录其位置继续探测；若最终未找到同 key，则在该 `DELETED` 槽插入（`deleted--`，`count++`）
- 若遇到 `EMPTY` 槽，直接在此插入（`count++`）
- 若找到同 key 的 `OCCUPIED` 槽，更新 value，返回 `ERROR`

**依赖接口（由系统提供，无需实现）：**
- `int Probe(OAHashTable* ht, int key, int i)`
