## 3920-创建最小堆

### 问题描述

最小堆（Min Heap）是一种完全二叉树，满足堆序性质：每个结点的值均不大于其子结点的值，因此根结点始终存储整个堆中的最小值。本实验采用**数组存储**实现，下标从 1 开始，`data[0]` 不使用。

---

## 数据结构定义

```c
typedef struct {
    int* data;      /* 元素数组，下标 1..size 有效，下标 0 不使用 */
    int  size;      /* 当前元素个数 */
    int  capacity;  /* 最大容量 */
} MinHeap;
```

---

## 函数说明

```c
MinHeap* CreateMinHeap(int capacity);
```

**参数：**
- `capacity`：堆的最大容量

**返回值：**
- 成功：返回初始化完成的 `MinHeap` 指针
- 失败（`capacity <= 0` 或内存分配失败）：返回 `NULL`

**初始状态要求：**
- `size` 初始化为 0
- `capacity` 初始化为传入值
- `data` 数组分配 `capacity + 1` 个 `int` 的空间（下标 0 预留不用，有效下标为 1..capacity）

**内存管理：**
- 函数内部分配内存，调用者需使用 `DestroyMinHeap` 释放

## 3928-下沉

### 问题描述

本题要求你实现**最小堆的下沉操作**。

下沉（SiftDown）用于在堆顶被替换或堆结构被局部破坏后，将指定位置的元素沿子节点方向逐步移动，直到堆序性质恢复。它是删除最小元素和建堆操作的核心辅助过程。

---

## 数据结构定义

```c
typedef struct {
    int* data;
    int  size;
    int  capacity;
} MinHeap;
```

---

## 函数说明

```c
void SiftDown(MinHeap* h, int i);
```

**参数：**
- `h`：最小堆指针
- `i`：起始位置（1-based 下标），通常为根节点（1）或某个内部节点

**功能：**
将位置 `i` 处的元素沿子节点方向向下调整，直到满足最小堆的堆序性质。仅在元素值严格大于子节点值时向下移动；等值时不移动。左右子节点均存在时，优先与值较小的子节点比较；两子节点值相同时，优先选择左子节点。

**返回值：**
无返回值（`void`）

**特殊情况：**
- `h == NULL` 或 `h->data == NULL` 时直接返回
- `i` 无左子节点时直接返回

## 3930-原地建堆

### 问题描述

本题要求你实现**最小堆的原地建堆操作**。

原地建堆（BuildHeap）是将一组任意顺序的元素批量构建为满足最小堆性质的完全二叉树，其堆化过程时间复杂度为 O(n)，比逐个插入（O(n log n)）更高效，适合批量初始化。

---

```c
typedef struct {
    int* data;      /* 元素数组，下标 1..size 有效，下标 0 不使用 */

    int  capacity;  /* 最大容量 */
} MinHeap;
```

---

```c

```

**参数：**

- `n`：数组元素个数

- 失败（`arr == NULL`、`n <= 0`、`capacity < n` 或内存分配失败）：返回 `NULL`
