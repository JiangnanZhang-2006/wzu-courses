## 4052-创建图

### 问题描述

本题要求你实现**邻接表无向图的初始化操作**。

本题使用**邻接表**表示无向图。图由若干顶点和边组成，顶点编号从 `0` 开始。每个顶点维护一条链表，链表中每个节点存储一个邻居顶点编号。`CreateGraph` 负责分配并初始化一张空图：分配头指针数组，将所有头指针置为 `NULL`，初始化顶点数和边数。

---

## 数据结构定义

```c
typedef enum { OK = 1, ERROR = 0 } Status;

typedef struct AdjNode {
    int             vertex;
    struct AdjNode* next;
} AdjNode;

typedef struct {
    AdjNode** heads;     /* 邻接表头指针数组，长度为 size */
    int       size;      /* 顶点数量 */
    int       edgeCount; /* 边数 */
} ALGraph;
```

---

## 函数说明

```c
ALGraph* CreateGraph(int size);
```

**参数：**
- `size`：顶点数量

**返回值：**
- 成功：返回新创建的图指针
- 失败（`size <= 0` 或内存分配失败）：返回 `NULL`

**初始状态要求：**
- `size` 初始化为 `size`
- `edgeCount` 初始化为 `0`
- `heads` 数组长度为 `size`，每个元素初始化为 `NULL`

**特殊情况：**
- `size <= 0` 时返回 `NULL`，不分配任何内存
