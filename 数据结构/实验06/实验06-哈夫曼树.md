## 3883-构建哈夫曼树

### 问题描述

本题要求你实现 **哈夫曼树的构建操作**。

哈夫曼树（Huffman Tree）是一种带权路径长度最短的二叉树，也称为最优二叉树，具有以下特点：

* 权值较大的结点离根较近
* 没有度为1的结点（只有度为0或度为2的结点）
* n个叶子结点的哈夫曼树共有2n-1个结点
* 是构造哈夫曼编码的基础

哈夫曼树常用于：

* 数据压缩编码
* 通信编码优化
* 最优判定树构建
* 文件压缩算法

构建哈夫曼树的基本思想是：

* 将所有结点初始化为独立的树
* 每次选择两个权值最小的结点合并
* 新结点的权值为两个子结点权值之和
* 重复上述过程直到只剩一个根结点

例如，给定字符数组 `{'A', 'B', 'C', 'D'}` 和权值数组 `{5, 9, 12, 13}`，构建出的哈夫曼树中：

* 叶子结点存储字符和权值
* 非叶子结点权值为子结点权值之和
* 最终根结点权值为所有叶子权值之和（39）

## 数据结构定义

你必须使用以下哈夫曼树结构定义完成本题：

```c
typedef struct {
    char data;        /* 字符数据 */
    int weight;       /* 权值 */
    int parent;       /* 父节点下标 */
    int lchild;       /* 左孩子下标 */
    int rchild;       /* 右孩子下标 */
} HTNode;

typedef struct {
    HTNode* nodes;    /* 节点数组 */
    int n;            /* 叶子节点数 */
    int size;         /* 总节点数(2n-1) */
} HuffmanTree;
```

说明：

* `data`：存储字符数据（仅叶子结点有效）
* `weight`：结点权值
* `parent`：父结点在数组中的下标，-1表示无父结点
* `lchild`：左孩子在数组中的下标，-1表示无左孩子
* `rchild`：右孩子在数组中的下标，-1表示无右孩子
* `nodes`：存储所有结点的数组（下标0到n-1为叶子结点，n到2n-2为非叶子结点）
* `n`：叶子结点数量
* `size`：总结点数量（等于2n-1）

## 3884-生成哈夫曼编码表

### 问题描述

本题要求你实现 **哈夫曼编码表的生成操作**。

哈夫曼编码是一种可变长度编码方式，具有以下特点：

* 根据字符出现频率（权值）分配编码长度
* 频率高的字符编码短，频率低的字符编码长
* 任何字符的编码都不是其他字符编码的前缀（前缀编码特性）
* 在所有前缀编码中，哈夫曼编码的平均编码长度最短

哈夫曼编码的生成规则：

* 从叶子结点向上追溯到根结点
* 若当前结点是父结点的左孩子，记录'0'
* 若当前结点是父结点的右孩子，记录'1'
* 将记录的编码串反转得到最终编码

例如，对于已构建好的哈夫曼树，某个字符从叶子到根的路径为：左-左-右，则其编码为"100"（反转后）。

编码表用于：

* 快速查找字符对应的编码
* 字符串编码操作
* 数据压缩算法
* 通信编码方案

带权路径长度（Weighted Path Length，WPL）是衡量哈夫曼树优劣的核心指标：

* WPL = Σ(wi × li)
* wi：第i个叶子节点的权值
* li：第i个叶子节点到根节点的路径长度

WPL的意义：

* 反映了哈夫曼编码的平均编码长度
* WPL越小，编码效率越高
* 哈夫曼树的WPL是所有二叉树中最小的
* 用于数据压缩率的理论分析

在数据压缩中：

* 每个字符的权值表示其出现频率
* 路径长度表示其编码长度
* WPL表示编码后的平均比特数
* 较小的WPL意味着更高的压缩率

计算方法：

* 遍历所有叶子节点
* 对每个叶子节点，计算其到根节点的路径长度
* 将权值与路径长度相乘后累加
