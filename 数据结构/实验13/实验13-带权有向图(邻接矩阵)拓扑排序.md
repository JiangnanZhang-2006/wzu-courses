## 4151-创建图

## 问题描述

本题要求你实现**带权有向图的初始化操作**。

## 数据结构定义

本题使用**带权邻接矩阵**表示有向图。`matrix[i][j]` 存储从顶点 `i` 到顶点 `j` 的有向边权重，值为 `0` 表示无边；顶点编号从 `0` 开始，矩阵需动态分配。

```c
typedef enum { OK = 1, ERROR = 0 } Status;

typedef struct {
    int** matrix;    /* matrix[i][j] = 权重，0 表示无边 */
    int   size;      /* 顶点数量 */
    int   edgeCount; /* 有向边总数 */
} WDGraph;
```

## 函数说明

```c
WDGraph* CreateGraph(int size);
```

**参数：**
- `size`：顶点数量

**返回值：**
- 成功：返回新创建的图指针；`size` 初始化为 `size`，`edgeCount` 初始化为 `0`，`matrix` 为 `size × size` 的二维数组，所有元素初始化为 `0`
- 失败（`size <= 0` 或内存分配失败）：返回 `NULL`
