## 3821-创建与初始化

### 问题描述

本题要求你实现**链队列**的创建与初始化操作。

链队列是队列的链式存储实现，具有以下特点：

* 使用链式存储结构（单链表）动态存储队列中元素
* 用 `front` 指针指向队头节点，`rear` 指针指向队尾节点
* 遵循 **FIFO（先进先出）** 原则
* 无固定容量限制（仅受系统内存限制）
* 通过动态分配节点实现入队和出队操作

---

## 队列类型定义

```c
typedef int ElementType;

typedef struct QNode {
    ElementType data;
    struct QNode* next;
} QNode;

typedef struct {
    QNode* front;  // 队头指针
    QNode* rear;   // 队尾指针
    int size;      // 队列长度(便于O(1)获取)
} LinkQueue;

typedef enum { OK = 1, ERROR = 0 } Status;
```

**功能要求**：

* 动态分配一个链队列结构体
* 将队头指针 `front` 和队尾指针 `rear` 都初始化为 `NULL`，表示空队列
* 将队列长度 `size` 初始化为 `0`
* 返回指向新创建队列的指针
* 若内存分配失败，返回 `NULL`

2. **动态内存分配**：使用 `malloc` 分配队列结构体，返回指针。
3. **front 和 rear 指针约定**：
   
   * `front == NULL && rear == NULL` 表示空队列

## 3824-入队

### 问题描述

本题要求你实现**链队列**的入队操作。

入队操作将一个新元素添加到队尾。链队列的入队操作通过动态分配新节点实现，理论上无容量限制（仅受系统内存限制）。

---

## 队列类型定义

```c
typedef int ElementType;

typedef struct QNode {
    ElementType data;
    struct QNode* next;

```

---

## 函数说明

你需要实现以下 **1 个函数**：

### 入队操作

```c
Status EnQueue(LinkQueue* Q, ElementType x);
```

**功能要求**：

* 将元素 `x` 添加到链队列 `Q` 的队尾
* 若队列指针 `Q` 为 `NULL`，返回 `ERROR`
* 若内存分配失败，返回 `ERROR`
* 操作成功后，更新 `size` 字段（`Q->size++`）
* 操作成功返回 `OK`

**入队步骤**：

1. 分配新节点，存储元素 `x`
2. 若队列为空（`Q->rear == NULL`），则 `front` 和 `rear` 都指向新节点
3. 若队列非空，将新节点链接到 `rear->next`，然后更新 `rear` 指针

### 【实现要求】

1. **动态内存分配**：使用 `malloc` 分配新节点 `sizeof(QNode)`。
2. **空队列特殊处理**：入队时需判断队列是否为空，空队列时 `front` 和 `rear` 都指向新节点。
3. **rear 指针更新**：非空队列时，新节点链接到 `rear->next`，然后 `rear` 指向新节点。

## 3825-出队

### 问题描述

本题要求你实现**链队列**的出队操作。

出队操作删除队头元素，并返回该元素的值。链队列的出队操作需要释放队头节点的内存，体现了链式存储的动态特性。

你需要实现以下 **1 个函数**：

### 出队操作

```c

```

**功能要求**：

* 删除链队列 `Q` 的队头元素，并通过指针 `x` 返回该元素的值
* 若队列指针 `Q` 为 `NULL` 或输出指针 `x` 为 `NULL`，返回 `ERROR`
* 若队列为空（无元素可出队），返回 `ERROR`
* 操作成功后，更新 `size` 字段（`Q->size--`）
* 若出队后队列变空，需将 `rear` 指针置为 `NULL`

1. 检查队列是否为空
2. 保存队头节点指针

5. 若队列变空（`front == NULL`），将 `rear` 也置为 `NULL`

## 3838-链队列实现栈

### 问题描述

本题要求你实现**链队列（LinkQueue）**的基础操作，以及使用**两个链队列实现栈（MyStack）**的功能。

栈是一种后进先出（LIFO, Last In First Out）的数据结构，而队列是先进先出（FIFO）。本题要求使用两个队列来模拟栈的行为，这是一道经典的数据结构转换问题。

**核心思想：**
- **push操作**：直接将元素入队到Q1
- **pop操作**：将Q1的前n-1个元素倒腾到Q2，弹出Q1的最后一个元素（栈顶），然后交换Q1和Q2
- **top操作**：类似pop，但不删除元素，需要将元素重新入队
