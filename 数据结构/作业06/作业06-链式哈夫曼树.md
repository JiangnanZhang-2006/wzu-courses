## 3904-取最小权值节点

### 问题描述

本题要求你实现**从节点指针数组中取出权值最小节点的操作**。

在构建链式哈夫曼树的过程中，需要维护一个节点指针数组。每次合并步骤需要：

* 从节点指针数组中找到权值最小的节点
* 将该节点从数组中移除（后续元素前移，数组大小减1）
* 返回被移除的节点指针，供调用者合并使用

本函数是构建链式哈夫曼树的核心辅助操作。

---

## 数据结构定义

你必须使用以下链式哈夫曼树结构定义完成本题：

```c
typedef struct HuffmanNode {
    char data;                   /* 字符数据(仅叶子节点有效) */
    int  weight;                 /* 权值 */
    struct HuffmanNode* lchild;  /* 左孩子指针，NULL表示无 */
    struct HuffmanNode* rchild;  /* 右孩子指针，NULL表示无 */
} HuffmanNode, *HuffmanTree;
```

说明：

* `data`：存储字符数据，仅叶子节点有效
* `weight`：节点权值
* `lchild`：左孩子指针，NULL 表示无左孩子
* `rchild`：右孩子指针，NULL 表示无右孩子

---

## 函数说明

你需要实现以下函数：

```c
HuffmanNode* FindMinAndRemove(HuffmanNode** nodes, int* size);
```

---

### 功能要求

该函数应完成以下功能：

1. 在 `nodes[0]` 到 `nodes[(*size)-1]` 中找到权值最小的节点。
2. 将该节点从数组中移除：被移除位置后面的元素依次前移，`*size` 减 1。
3. 返回被移除节点的指针。
4. 若 `nodes == NULL`、`size == NULL` 或 `*size <= 0`，返回 `NULL`。

---

### 选择规则（保证结果唯一）

* 权值最小者优先。
* 权值相同时，取下标最小者（即先加入数组者优先）。

## 3905-链式构建哈夫曼树

### 问题描述

本题要求你实现**链式存储的哈夫曼树构建操作**。

与数组存储不同，链式哈夫曼树中每个节点通过指针链接，无需预分配固定大小的数组：

* 为每个字符创建一个独立的叶子节点，放入节点指针数组
* 每次从数组中取出两个权值最小的节点合并为新节点
* 新节点的权值为两个子节点权值之和，第一次取出的节点作左孩子，第二次取出的节点作右孩子
* 重复 n-1 次后，数组中唯一剩余的节点即为哈夫曼树根节点

---

## 数据结构定义

你必须使用以下链式哈夫曼树结构定义完成本题：

```c
typedef struct HuffmanNode {
    char data;
    int  weight;
    struct HuffmanNode* lchild;
    struct HuffmanNode* rchild;
} HuffmanNode, *HuffmanTree;
```

---

## 函数说明

你需要实现以下函数：

```c
HuffmanTree CreateHuffmanTree(char chars[], int weights[], int n);
```

---

### 功能要求

该函数应完成以下功能：

1. 根据 `chars` 和 `weights` 构建链式哈夫曼树，返回根节点指针。
2. 若 `chars == NULL`、`weights == NULL` 或 `n <= 0`，返回 `NULL`。
3. 若动态内存分配失败，返回 `NULL`。
4. 构建过程必须调用 `FindMinAndRemove` 函数。

---

### 构建规则

* 为每个字符分配一个 `HuffmanNode`，`lchild` 和 `rchild` 均为 `NULL`。
* 将 n 个节点放入节点指针数组（大小分配为 2n 即可保证足够）。
* 循环 n-1 次：
  * 调用 `FindMinAndRemove` 取出权值最小节点 `min1`，作为新节点的**左孩子**
  * 调用 `FindMinAndRemove` 取出权值次小节点 `min2`，作为新节点的**右孩子**
  * 分配新节点：`weight = min1->weight + min2->weight`，`lchild = min1`，`rchild = min2`，`data = '\0'`
  * 将新节点追加到数组末尾
* 最终数组中剩余的唯一节点即为根节点

---

### 唯一性保证

* `FindMinAndRemove` 在权值相同时取下标最小者
* 每次第一次取出的节点固定作左孩子，第二次取出的节点固定作右孩子
* 上述规则保证相同输入必然生成完全一致的哈夫曼树结构

---

### 辅助函数说明

你可以直接调用以下辅助函数（已在测试代码中提供）：

```c

```

**功能：** 从节点指针数组中取出权值最小的节点（权值相同时取下标最小者），数组大小减 1，返回该节点指针。

* 字符为不重复的大写字母 A-Z
* 权值范围：1 ≤ weight ≤ 100

## 3906-递归生成链表编码表

### 问题描述

本题要求你实现**对链式哈夫曼树进行前序递归遍历、生成链表编码表的操作**。

哈夫曼编码表记录每个字符与其对应哈夫曼编码的映射关系。与数组式编码表不同，链表编码表中每个编码节点通过 `next` 指针相连：

* 对链式哈夫曼树做前序遍历
* 向左走时记录 `'0'`，向右走时记录 `'1'`
* 到达叶子节点时，将字符及其完整编码以**头插法**写入链表

---

```c

    char data;

} HuffmanNode, *HuffmanTree;

typedef struct CodeNode {
    char ch;           /* 字符 */
    char code[256];    /* 哈夫曼编码字符串 */
    struct CodeNode* next;
} CodeNode;
```

## 3908-获取哈夫曼树高度

### 问题描述

本题要求你实现**链式哈夫曼树高度的递归计算操作**。

树的高度定义为根节点到最远叶子节点路径上的节点数。在链式存储中，需要通过递归方式遍历左右子树计算高度：

* 空树高度为 0
* 叶子节点高度为 1
* 非叶子节点高度 = max(左子树高度, 右子树高度) + 1

哈夫曼树的高度反映了最长编码的长度，权值分布越不均匀，树的高度往往越大。

---

### 计算规则

## 3910-计算带权路径长度

### 问题描述

本题要求你实现**链式哈夫曼树带权路径长度（WPL）的递归计算操作**。

带权路径长度 WPL = Σ(wi × li)，其中 wi 为第 i 个叶子节点的权值，li 为该叶子节点到根节点经过的边数（深度）。

与数组存储不同，链式树中无法直接查找父节点，需要在递归下行时传递当前深度，到达叶子时计算 weight × depth 并累加。

```c
    struct HuffmanNode* lchild;
    struct HuffmanNode* rchild;
```

---

### 功能要求

## 3919-计算哈夫曼编码压缩率

### 问题描述

本题要求你实现**计算哈夫曼编码相对于等长编码的压缩率的操作**。

哈夫曼编码的核心优势在于利用字符出现频率的差异，为高频字符分配短编码、低频字符分配长编码，从而使整体编码长度最短。

**压缩率**衡量哈夫曼编码相对于等长编码节省了多少空间：

```
等长编码位数 = totalWeight × fixedBits
哈夫曼编码位数(WPL) = Σ(weight_i × codelen_i)
压缩率 = (等长编码位数 - WPL) / 等长编码位数
```

其中：

* `totalWeight`：所有叶子节点权值之和（即字符出现总次数）
* `fixedBits`：等长编码每个字符所需位数，等于 ⌈log₂n⌉（n 为字符种类数）
  * n=1 时取 1；n=2 时取 1；n=3~4 时取 2；n=5~8 时取 3，依此类推
* `WPL`：哈夫曼树的带权路径长度

例如，n=4 个字符（fixedBits=2），总权值为 100，WPL=180，则压缩率 = (200-180)/200 = 0.1。
